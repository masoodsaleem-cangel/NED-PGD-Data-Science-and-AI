          |  - Average WiFi signal strength              |

                               |
                               v

          |  - LOW_OCCUPANCY: People > 0                 |
          |  - EMPTY: People = 0                         |

                               |
                               v
          +-----------------------------------------------+

          |  - Time stamp                                 |
          |  - People count (colored)                    |

          |  - Movement score                            |
          |  - Status (colored)                          |
          +-----------------------------------------------+
                               |
                               v
          +-----------------------------------------------+
          |  5. SAVE TO CSV                               |
          |  - Append to single CSV file                 |
          |  - Remove color fields                       |
          |  - Write header only once                    |
          |  - Convert BT names to string                |
          +-----------------------------------------------+
                               |
                               v
          +-----------------------------------------------+
          |  CHECK: Ctrl+C Pressed?                       |
          +-----------------------------------------------+
                    |                           |
                   No                          Yes
                    |                           |
                    v                           v

          |  - Calculate statistics                       |
          |  - Session duration                           |
          |  - Total samples                              |
          |  - Average/Peak people                        |
          |  - Average/Peak movement                      |
          |  - Save final CSV                             |

                                   |
                                   v
          +-----------------------------------------------+
          |  7. CREATE 3 PLOTS                            |

          |                                              |
          |  Plot 2: WiFi Signal & Changes               |
          |    - Signal strength line chart              |
          |    - WiFi changes bar chart (secondary axis) |
          |    - Weak signal threshold line              |
          |                                              |
          |  Plot 3: Movement & BT Changes               |
          |    - Movement line chart                     |
          |    - BT changes bar chart (secondary axis)   |

                                   v

          |  - Duration                                   |

                                   |
                                   v

+====================================================================+
|                    COLOR CODING LEGEND                              |
+====================================================================+

Signal Strength (dBm):
  >= -50  : 🟢 Excellent (Green)
  -50 to -60 : 🩵 Good (Cyan)
  -60 to -70 : 🟡 Fair (Yellow)
  < -70   : 🔴 Poor (Red)

Occupancy Status:
  HIGH_TRAFFIC   : 🔴 Red
  MEDIUM_TRAFFIC : 🟡 Yellow
  OCCUPIED       : 🩵 Cyan
  LOW_OCCUPANCY  : 🟢 Green
  EMPTY          : 🔵 Blue
